# Loop di intervista

```
evidenza (PRD/mockup/file/chat)
  → bozza / ipotesi etichettate
  → 1–2 domande al PO
  → sintesi + conferma
  → aggiorna draft
  → (ripeti finché stop condition)
  → export file
```

## Formato risposta tipico (turno)

```
## Capito finora
- …

## Da confermare
1. …?
2. …?   # max 2
```

## Quando non chiedere

- Il PO ha già risposto in modo chiaro nella stessa sessione
- L’informazione è esplicita nell’artefatto upstream caricato
- Stai solo mostrando un report read-only (`/show`, `/gap`, `/triage` senza ambiguità)
