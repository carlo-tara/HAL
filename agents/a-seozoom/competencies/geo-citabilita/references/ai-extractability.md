Studi terzi su lunghezze passaggio diverse: citare fonte; **non** imporre soglie progetto inventate.

## Pattern blocco (sintesi)

- **Definition** — 1 frase definizione + 1–2 espansione
- **How-to** — overview + step numerati (contenuto; non HowTo rich result)
- **Comparison** — tabella + bottom line
- **FAQ** — domanda H2/H3 + risposta diretta poi contesto
- **Statistic** — numero + data + fonte linkabile

Corpo lungo / humanize → **a-copywriter**. Title/meta/FAQ corte → `onpage-seo` + `tono-di-voce`.  
Schema → `schema-markup` + [deprecated-rich-results](../../schema-markup/references/deprecated-rich-results.md).
