## Quando applicare

Copy in italiano nativo, blog narrativi, email, microcopy. Controllo grammaticale post-draft su testi che suonano «corretti ma strani».

---

## Il problema del tempo piatto

Gli LLM schiacciano tutto su presente indicativo o passato prossimo standardizzato.

| Dimensione | Errore LLM | Uso umano | Regola |
|------------|------------|-----------|--------|
| **Pro-futuro** | *La settimana prossima inizieremo* | *La settimana prossima iniziamo* | Presente per imminenza (email, articoli disinvolti) |
| **Futuro epistemico** | *Il server è andato in down ieri* (certezza) | *Il server sarà andato in down ieri* | Futuro per supposizione/dubbio |
| **Passato narrativo** | *Nel 2010 ho iniziato* (sempre) | *Nel 2010 iniziai* / *bazzicavo* | Passato remoto per distanza psicologica o tono narrativo |
| **Neo-formazioni** | *lavorare in remote*, *smart working* | *lavoro a distanza*, *lavoro agile* | Preferisci italiano consolidato o descrittivo |

## Matrice tempi — copy web

| Contesto | Preferisci |
|----------|------------|
| E-commerce, scheda prodotto | Presente descrittivo (*«è realizzato»*, *«resta»*) |
| Blog narrativo / case study | Passato remoto per aneddoti lontani; imperfetto per «set» |
| CTA imminente | Presente pro-futuro (*«domani apriamo»*) |
| FAQ tecniche | Presente o imperfetto di consuetudine |

Non correggere pro-futuro in futuro se il brand file indica registro informale.

## Reggenze e clitici (Crusca)

### Ausiliare di *resistere*

*Resistere* è intransitivo → **avere** (*«ho resistito»*, mai *«sono resistito»*).

### Clitici dativi (complemento di termine)

Quando riprendi argomento con preposizione *a*:

| Contesto | ❌ Errore AI | ✅ Corretto |
|----------|-------------|-------------|
| Femminile (*la tentazione*) | *l'ho resistito* | *le ho resistito* |
| Maschile (*il richiamo*) | *non l'ho resistito* | *non gli ho resistito* |
| Astratto/plurale (*distrazioni*) | *non posso resisterle* | *non ci posso resistere* / *non posso resistervi* |

### Check morfosintattico

1. Verbi intransitivi attivi (*resistere*, *insistere*, *desistere*) → ausiliare **avere**
2. Ripresa con *a* → clitico **dativo** (le/gli/ci/vi), mai accusativo (la/lo/li/le)
3. Dislocazione a sinistra OK se coerente: *«Alla tentazione, non le ho resistito»*

## Esempi copy web

| ❌ Rigido / AI | ✅ Vivo |
|---------------|---------|
| Il server è andato in down ieri pomeriggio. | Il server sarà saltato ieri pomeriggio, o almeno così ci è sembrato dal monitor. |
| La prossima settimana lanceremo la nuova collezione. | La prossima settimana lanciamo la nuova collezione. |
| Nel 2015 abbiamo aperto il laboratorio. | Nel 2015 aprimmo il laboratorio, in un locale che oggi non esiste più. |

## Priorità con brand file

Se il brand file impone registro formale (Lei, tono istituzionale) → preferisci futuro esplicito e passato prossimo. Le regole di vitalità si adattano al registro, non lo sovrascrivono.
