## Quando applicare

Tutti i copy in italiano, salvo brand file che esplicitamente ammette inglesismi (es. SaaS internazionale). Nel dubbio → purismo attivo.

---

## Regola madre (audit interno)

> Se un termine o costrutto inglese può essere rimpiazzato da italiano equivalente senza suonare arcaico, sostituisci immediatamente.

**Eccezioni buon senso (2026):** termini tecnici consolidati (*software*, *computer*, *agent*, *browser*, *email*, *online*, *SEO*, *CMS*, nomi prodotto).

## Slang generazionale

Evita slang Gen Z fuori contesto: *hype*, *crush*, *skippare*.

OK espressioni pop anni '90/2000 se coerenti con brand: *roba da matti*, *fare terra bruciata*.

---

## *Piuttosto che* (non disgiuntivo)

Significa **invece di**, mai *oppure* (Crusca / Treccani).

| ❌ | ✅ |
|----|-----|
| *pizza piuttosto che pasta* (per *o*) | *pizza o pasta* |
| *Preferisco A piuttosto che B* (*invece di*) | OK |

Ogni *piuttosto che* nel copy: verifica il senso.

## Falsi amici (EN → IT sbagliato)

| Parola | ❌ senso EN | ✅ italiano |
|--------|-------------|-------------|
| realizzare | *mi sono reso conto* | attuare / *mi sono reso conto che* |
| attuale | *reale* (*actual*) | di oggi; per *reale* usa *reale* |
| eventualmente | *alla fine* (*eventually*) | se del caso |
| consistente | *coerente* (*consistent*) | corposo; per coerenza → *coerente* |
| supportare | *sostenere un'idea* | peso fisico; idea → *sostenere / appoggiare* |
| assolutamente | *Assolutamente!* = sì | *certamente / senz'altro* |
| fare senso | *make sense* | *avere senso* (*fare senso* = ribrezzo) |
| educato | *istruito* | cortese; istruito → *istruito / colto* |
| sensibile | *ragionevole* (*sensible*) | che prova emozioni; ragionevole → *ragionevole* |
| libreria | *library* | negozio libri; biblioteca → *biblioteca* |
| editore | *editor* (persona) | casa editrice; persona → *curatore / editor* (se brand) |

## Verbi ibridi

Evita (salvo glossario brand esplicito): *sharare*, *downloadare*, *uploadare*, *brieffare*, *pitchare*, *forwardare*, *scheduleare*.

Preferisci: *condividere*, *scaricare*, *caricare*, *fare il brief*, *presentare*, *inoltrare*, *fissare*.

## Checklist purismo

- [ ] Zero idiom inglesi non tradotti
- [ ] Zero corporate slop sostituibile
- [ ] Zero falsi amici / verbi ibridi sostituibili
- [ ] *Piuttosto che* solo comparativo
- [ ] Termini tecnici EN solo se consolidati o nel glossario brand
- [ ] Calchi sintattici EN corretti (SVO rigido, nominalizzazioni)
- [ ] Suona italiano dell'uso medio, non traduzione letterale
