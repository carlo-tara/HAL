# illustrator — Visual Assets & Illustration Pipeline

Skill per la generazione di illustrazioni coerenti e asset visivi AI. Competenza integrata di **a-design**.

---

## Competenze integrate

- `stile-visivo`: Onboarding, style file, coerenza visiva
- `prompt-composizione`: Formula prompt, varianti A/B/C
- `preview-render`: Anteprime → render via script
- `qa-artefatti`: Ispezione artefatti AI
