# charts — Data Visualization & Effective Charts

Skill di Data Visualization e grafici efficaci. Competenza integrata di **a-design**.

---

## Principio guida

> Un grafico buono risponde a **una domanda** in pochi secondi. Se il lettore deve studiare la legenda, decodificare colori o confrontare angoli, riprogetta.

Priorità:
1. **Messaggio** — quale confronto / trend / composizione deve emergere?
2. **Tipo** — encoding più diretto (posizione > lunghezza > angolo > area)
3. **Declutter** — togli tutto ciò che non serve alla lettura
4. **Etichette** — unità, fonte, periodo; etichette dirette quando possibile
5. **Stack progetto** — riusa token/UI esistenti

---

## Competenze integrate

- `scelta-tipo`: Intent → tipo grafico
- `leggibilita`: Encoding, declutter, accessibilità
- `implementazione`: Target di output (SVG, D3, canvas, HTML, Python)
- `qa-grafici`: Checklist pre-consegna
