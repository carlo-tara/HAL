# Add-scenario workflow (`/add-scenario`)

1. Interpreta NL del PO
2. Cerca Feature file esistente del flusso (preferisci aggiungere Scenario lì)
3. Nuovo file solo se nuovo flusso/capability
4. Collega seed/need se esistono; altrimenti tagga hypothesis fino a conferma
5. Aggiorna inventory UI/IO se introduce controlli/fonti
6. Draft → conferma → export
