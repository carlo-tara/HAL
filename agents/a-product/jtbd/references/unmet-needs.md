# Unmet needs

## Pass analitico (6 lenti)

1. Gap goal → successo
2. Pain → need
3. Constraint friction
4. Skill mismatch
5. Flow / continuity gaps
6. Trigger → drop-off

## Pass intuitivo

Max 3–5/persona/turno; sempre `hypothesis` fino a conferma PO.

## Scoring

`opportunity = importance + max(importance - satisfaction, 0)` con `method: po_estimate` se non c'è survey.

Hypothesis fuori da `unmet_ranking` attivo.
