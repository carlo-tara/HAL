# Timeline markers — switch interview

Fonte metodo: Moesta & Spiek (jobstobedone.org). Distillato per HAL.

La **timeline** = *how* dello switch. Le **Four Forces** = *why*. Si usano insieme.

## Sequenza

```
First Thought → Passive Looking → Event 1 → Active Looking → Event 2 → Decision/Purchase → Consumption
```

| Marker | Cosa |
|--------|------|
| **First Thought** | Momento in cui nasce “potrebbe servirmi qualcosa di diverso”. Spesso **più indietro** di quanto dicono — probe: “cosa c’era *prima*?” |
| **Passive Looking** | Bassa energia: notano, archiviano, nessun urgency. Soft signal ok; hard sell bounce |
| **Event 1** | Soglia: da “dovrei” a “devo fare qualcosa”. Push/pull intensificano |
| **Active Looking** | Shopping = **shaping the job** (trade-off), non solo feature compare |
| **Event 2** | Trigger finale (spesso time wall / deadline / click emotivo) |
| **Decision / Purchase** | Push+Pull superano Habit+Anxiety |
| **Consumption** | *In the mind* al purchase (aspettative) vs *actual* all’uso — gap = soddisfazione |

Scale: da frazioni di secondo (impulse) a anni (enterprise) — stessa sequenza.

## Bounce (in interview)

Non camminare solo in ordine. Esempio: menzionano l’acquisto → salta a First Thought; menzionano un amico → “quando? dove cade sulla timeline?”.

Nota operativa: marca **Bought** per primo, poi posiziona eventi man mano che emergono; i gap restano visibili.

## During guide — checklist gaps

- [ ] First Thought vero (non solo “quando ho cercato su Google”)
- [ ] Passive vs Active distinti
- [ ] Event 1 e Event 2 identificati (anche se deboli)
- [ ] Almeno un workaround / alternativa rifiutata
- [ ] Momento “this is the one” (tipping)
